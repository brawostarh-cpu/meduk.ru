# Контент Meduk: рабочие черновики

Материалы в `content/drafts/` не подключены к публичной навигации. Это редакционный слой фазы B: каждый текст содержит вопрос, уровень доказательности, ограничения и ссылки на первоисточники. Перед публикацией нужен фактчекинг и ревью владельца.

Проверка:

```bash
npm run check:content
```

Источники проверялись 09.09.2026 через PubMed, PLOS ONE и страницы издателей. Скрипт проверяет структуру и стоп-слова, но не заменяет содержательное научное ревью.
