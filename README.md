# meduk.ru

Исходники текущей версии сайта Meduk Relax.

## Структура

- `index.html`, `app.js`, `audio.js`, `styles.css`, `stats.js`, `theme-init.js` — PWA-плеер и интерфейс.
- `assets/` — изображения, иконки и локальные шрифты.
- `admin/` — серверная админка и правила доступа.
- `collect.php`, `pulse.php` — серверные точки аналитики.
- `sw.js`, `manifest.webmanifest` — офлайн-режим и установка приложения.
- `MEDUK_MASTER_PLAN_VSE_15_VERSIJ.md` — единый план, инварианты и контрольные ворота.

## Запуск

Для статической проверки интерфейса можно использовать любой локальный HTTP-сервер из корня проекта, например:

```bash
python3 -m http.server 4173 --bind 0.0.0.0
```

Открывать нужно `http://127.0.0.1:4173/`. Для проверки PHP-аналитики и админки нужен PHP 8.x с веб-сервером; запускать PHP-исходники как статические файлы нельзя.

## Ограничения публичного запуска

В репозитории нет боевых ключей, реальной платёжной интеграции, SMTP и данных пользователей. Платёжный и аккаунтный контуры из мастер-плана нельзя считать готовыми к production только по наличию локального UI. Перед публичным платным запуском обязательны контрольные ворота из мастер-плана и ручное подтверждение владельца.

Данные `.meduk-data`, секреты, резервные копии и локальные тестовые данные не добавляются в репозиторий.
